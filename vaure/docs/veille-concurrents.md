# VAURE – Veille concurrents (10 min par jour)

## La routine
1. Une pub de bijoux apparaît sur Instagram ou TikTok → je la regarde jusqu'au bout.
2. Je clique, je parcours la fiche, j'**ajoute au panier** (l'algorithme me montrera plus de pubs e-commerce).
3. Je vais jusqu'à la page de paiement, **sans payer**.
4. Je remplis une ligne de la grille ci-dessous.

Bonus : la **Bibliothèque publicitaire Meta** (facebook.com/ads/library) montre toutes les pubs actives d'une marque. Une pub active depuis plus de 30 jours est presque toujours une pub qui vend.

## La grille (une ligne par marque)

| Question | Ce que j'observe |
|---|---|
| Marque / lien | |
| Pub : accroche des 3 premières secondes | |
| Pub : format (vidéo face caméra, gros plan, avant/après…) | |
| Produit présenté : plutôt émotion ou plutôt fonction ? | |
| Matière écrite clairement ? (acier, plaqué, laiton…) | |
| Prix et offre (1 acheté = 1 offert, lot de 3, −10 %…) | |
| Pourquoi cette offre ? (justification donnée ou non) | |
| « Livraison offerte » ou « gratuite » ? À partir de combien ? | |
| Délai de livraison annoncé (et honnête ?) | |
| Fiche produit : ordre des blocs (photos, prix, bénéfices, avis, FAQ) | |
| Photos : portées, gros plans, vidéo, fond blanc ? | |
| Copywriting : 1 phrase que j'aurais aimé écrire | |
| Confiance : avis, garanties, retours, paiement | |
| Page de paiement : logo, couleurs, upsell ? | |
| ✅ À reprendre chez VAURE | |
| ❌ À éviter (faux stock, faux compte à rebours, prix barré douteux…) | |

## Ce que je compare toujours à VAURE
- Leur promesse est-elle plus claire que « des bijoux qui ne noircissent pas » ?
- Leurs photos me font-elles plus envie que les nôtres ?
- Leur offre est-elle plus simple que « −10 % dès 2 articles » ?
- Leur délai est-il plus court ? Le disent-ils honnêtement ?

## Une fois par semaine
Je choisis **une seule** idée à tester chez VAURE (une accroche, une photo, une phrase de fiche) et je l'envoie à Claude pour l'appliquer au site ou aux pubs.

Règle : on s'inspire de la structure et des idées, on ne copie jamais les textes, les photos ou le nom d'une autre marque.
