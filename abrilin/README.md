# Abrilin

Boutique mono-niche : rideaux thermiques et occultants aspect lin, en dropshipping (CJ), construite avec la méthode Scutify.

- `site/` : site de démonstration (HTML, CSS, JS sans framework). Le message s'adapte à la saison ; Noël et Black Friday ne s'affichent qu'à leurs vraies dates. Réglages dans `CONFIG`, en haut de `app.js`.
- `docs/plan-scutify.md` : niche, catalogue, marges, urgence, pubs, validation, mise en place Shopify.

Lancer en local :

```bash
cd site && python3 -m http.server 8000   # puis http://localhost:8000
```

Règles : une seule niche ; pas de faux avis, faux stock ni faux compte à rebours ; ne jamais suggérer une fabrication française ou artisanale ; illustrations à remplacer par les photos des échantillons.
